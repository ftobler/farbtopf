# Farbtopf
A tiny paint pot for your browser.

---

This is a MS-Paint clone. The win10/win11 version.

It is made for Github pages to be a handy tool for quickly annotating or editing images. Without much fuss and too complex of an UI like e.g Gimp.

React/Typescript, test driven development. Dark/Light mode.
